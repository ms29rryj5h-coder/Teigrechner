# Pizzateig-Rechner – Zwei & Knusprig

Online-Rechner zum Pizza-Grundkurs von Zwei & Knusprig (Chemnitz).

- Zwei Rezepte: ohne Vorteig und mit Poolish
- Anzahl Teigballen, Ballengewicht, Hydration, Zeiten und Temperaturen frei einstellbar
- Hefemenge nicht linear: Zeit und Temperatur gehen über ein exponentielles Wachstumsmodell ein, die Teigmenge leicht unterproportional
- Zeitplan ab gewünschtem Backzeitpunkt, Zutatenliste zum Abhaken, Anleitung mit den aktuellen Werten
- Eine einzige Datei (`index.html`), läuft komplett im Browser

Direkt zum Rezept: `#ohne-vorteig` oder `#poolish` an die Adresse anhängen.
